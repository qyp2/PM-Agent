# S82 资讯订阅消化

## 用途

给**定时资讯订阅**用：按用户主题与关注实体做增量检索，只交桥接能解析的条目块。检索策略继承 **S81 商机雷达**（香港本土优先、多路 websearch、防幻觉），本技能只改「交卷格式」和「关注实体加权」。

## 调用方

- 主代理：**A81（pm-a81-opportunity）**
- 任务说明里会写 `技能: s82-intel-digest`；看到后只加载本技能，不要再自行改去 S81 卡片模板。

## 立场

中国移动香港（CMHK）。香港本土机构动向、政策、资助、招标优先于大湾区与大陆资源。

## 检索（先做这些）

1. 先读任务里的「高亮/关注实体」列表；实体名必须放进**前几轮** websearch Query（加引号或作为必现词），再拼领域扩展词。
2. 领域扩展与多路搜索按 **S81**：香港机构动向 → 香港活动 → 香港新闻 → 大湾区补充 → 大陆优质垫底。
3. 只用 websearch / webfetch。不要假设存在 Tavily、Serper 或其他外挂搜索 API。
4. 任务里「已经推过」「不感兴趣」的链接与题目一律跳过，不要换标题复述。

## 交卷格式（硬约束）

桥接只认下面的标记。不要写开场白，不要商机雷达推荐卡片模板，不要 `[[send-file]]`，不要生成文件。

- 没有任何新条目时，只输出一行：`@@EMPTY`
- 有新条目时，每条一块，最多 5 条；没有可打开的 http(s) 链接就不要写该条：

```
@@ITEM
标题: …
日期: YYYY-MM-DD（原文没有就写待核实）
链接: https://...
摘要: 不超过80字
实体: 命中的关注实体名；未命中可留空
@@END
```

## 防幻觉

- 标题、日期、链接、摘要只写搜索结果里能核对到的内容。
- 链接必须真实可打开；编造链接禁止。
- 结果不足时输出 `@@EMPTY` 或更少条目，不要硬凑。
