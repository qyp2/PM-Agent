# S33 产品退出材料技能

## 用途
产出产品退出评审材料，回答五个决策问题：产品是否可退出（战略/财务/业务/市场）、退出方案是否可行、客户安置是否妥当、合作终止方案是否可行、各部门分工与前线口径是否到位。

## 格式询问（先问再写）
- 用户未说明输出格式时，先询问：要 PPT 汇报材料、Word 方案报告，还是 Markdown 摘要？得到答复后再动笔。
- 默认建议 PPT。

## PPT 结构参考
下列每一大标题下必须覆盖的内容；页数不限于 10 页，内容多时一个大标题拆成多页。
1. **封面**：标题《产品管理跨部门协调工作组-XXX产品退出评审》、汇报部门、日期（YYYY年X月）、中国移动标识。
2. **产品介绍**：业务信息（推出时间、服务功能、资费、客户类型、合作模式、设备、申请/取消渠道）；运营数据（产品外观、月活 MAU、总用户数、收入趋势图表）。
3. **产品退出原因**：六个维度剖析——平台再发展可行性低、产品形态受限、市场需求不足、销售模式瓶颈、网络安全风险、合作商终止服务。
4. **产品销售数据**：最后一单销售时间及合约到期情况；当前活跃用户情况（如"目前已无客户正在使用该产品服务"）；历年销售数量与收入表格。
5. **退出的法务指引**：法务部门合规意见、风险规避建议、用户/合作商协议解约条款履约分析。
6. **客户安置计划**：存量用户盘点、平滑迁移/替代推荐方案、退费补偿标准及客诉应急预案。
7. **合作终止执行方案（如涉及）**：合作方盘点、商务结算清算（底价/分成）、违约责任划分及业务交接。
8. **前线销售/客服口径**：五大场景 Q&A——新业务/替代品查询路径；历史记录保留与查询期限；数据隐私脱敏安全承诺；非强制变更承诺（"仅向用户推荐，不强制更换"）；替代产品差异化优势对比。
9. **下线计划及影响分析**：8 步节点流程（法务咨询评估 → 编制客户安置计划和退出方案 → 产品退出说明会 → 领导专题办公会决策 → 邮件通知相关部门 → 提交 IT 需求 → 正式下线 → 下线后 3 个月内完成固定资产注销）；影响评估、影响用户及替代方案。
10. **请示内容**：规范尾页——「拟正式推动【XXX产品名】业务下线。请领导批示！」

## 输出
- 退出评审材料正文（按所选格式）

## 约束
- 销售数据、法务意见、合作条款不得编造；未知处标注`【假设】`/`【待确认】`。
- 对外口径与补偿承诺需人工审批（R-11）。
