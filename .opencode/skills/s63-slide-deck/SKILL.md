# S63 幻灯片大纲

## 用途
用户要 ppt 或 pptx 时，在落盘前把每一节写成下面的结构。成稿命令套用母版 `pm-agent.potx` 的封面版式（`3_自定义版式`）与内容版式（`统一模板`），自动补封面页和页码。一个 `##` 是一节；正文写不完会自动续页，表格、图表各自单独成页，后续页标题带「（续）」。节数达到 5 个时命令自动补一页目录。正文不要再写「目录」「封面」「谢谢」。明细和多列清单写成 Markdown 表格。占比写成饼图，趋势写成柱状图，对比写成条形图。材料里有几种数字，就用几种图。

## 每一节

```markdown
## 页标题
副标题点明这一节

这一节用完整句子写清楚，保留名称、数字和时间，不要把一段话收成一个词。

- 要点
- 要点
```

占比用：

```chart pie
| 项目 | 占比 |
| --- | --- |
| 名称 | 原样数字 |
```

趋势用柱状图：

```chart column
| 项目 | 数值 |
| --- | --- |
| 名称 | 原样数字 |
```

对比用条形图：

```chart bar
| 项目 | 数值 |
| --- | --- |
| 名称 | 原样数字 |
```

## 成稿命令

页面写好后，只运行这一条命令。不要再找别的转换器，也不要另写说明文件。

`node ../.opencode/tools/build-deck.mjs --markdown "deliverables\文件.md" --out "deliverables\文件.pptx"`

需要套用用户给的模板时再加 `--template "模板.pptx"`；不传时用仓库自带的
`.opencode/templates/master/pm-agent.potx`。命令是自包含的（不依赖 Feishu-Bridge
或任何外部转换器），路径含空格时保留双引号。不要自己打开 pptx。

命令成功时只打印一行 JSON，例如
`{"ok":true,"path":"...","bytes":8961481,"slides":9,"layouts":[...],"warnings":[]}`。
`warnings` 非空表示有条目超额或字号被压缩，回传 A0 时要说明；`ok:false` 时把
`message` 原样引用，不要给出 pptx 路径。

## 规则
- 一个 `##` 是这一节的主标题。这一节可以变成多页：正文超过 5 条要点续页，表格超过 7 行续页，图表单独成页。
- 标题下面单独一行、不超过 28 个字、并且不以句号、叹号或问号结尾的短句，才会显示成副标题。更长的句子，以及带句号的句子，是正文。
- 要点用 `- `。一段写不完就继续写。
- 多列清单、名单、需要逐项对照的数据写成 Markdown 表格，这些表会保持为表格。
- 占比、构成、分布写成 `chart` 里的 `pie`。趋势写成 `column`。对比写成 `bar`。第一行是表头，后面每行一个名称和一个数字，最多 8 行。数字保持原文，不要改单位；需要单位时写在围栏行里，例如 `chart bar 单位:%`。
- 图表按原生形状绘制（不嵌入 Excel 对象），换机器不会变形：`pie` 是 100% 堆叠条 + 图例，`column` 是竖柱，`bar` 是横条。
- 不要写 `**加粗**`、`__下划线__`、行内代码或图片语法。
- 没有内容的节写一行 `- 未提供`。
- 不要写目录页和尾页，命令会按母版补上。
