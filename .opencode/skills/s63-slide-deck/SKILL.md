# S63 幻灯片大纲

## 用途
用户要 ppt 或 pptx 时，在落盘前把每一节写成下面的结构。成稿命令套用母版
`pm-agent.potx` 的封面版式（`3_自定义版式`）与内容版式（`统一模板`），自动补封面
页和页码。一个 `##` 是一节；正文写不完会自动续页，表格、图表各自单独成页，后续页标题
带「（续）」。节数达到 5 个时命令自动补一页目录。正文不要再写「目录」「封面」「谢谢」。

同一页的内容越具体，版式越立体：本节开头一句短话会成为页首导语；2–4 条「数字 + 说明」
的要点会变成指标卡；`### 小标题` 加短句会变成三栏卡片；有序列表会变成编号流程；
节末的 `>` 引用会变成底部结论条；`---` 会变成章节过渡页。全是长段落的页只会排成要点
列表，尽量少出现。

## 每一节

```markdown
## 页标题
副标题点明这一节

这一节开头用一句话说清结论，它会显示成页首导语。

- 要点
- 要点

> 这一节的结论，显示成页面底部的结论条
```

### 指标页（2–4 条，数字开头）

```markdown
## 关键数字

- 1,633万 2029 期末 ARR｜自下而上测算
- 4–5个月 SaaS 现金回本｜2029 口径
- 约 9–10x SaaS LTV/CAC｜CAC 0.6–0.66 万
```

数字在前、说明在后，`｜` 之后是口径注释（会排成卡片底部的小字）。数字必须带单位
（`%`、`万`、`个月`、`倍`、`人`…），说明 22 字以内。

### 金句页（整节只有一句话）

```markdown
## AI 让分析内容的消费者变成生产者

> 到 2026 年，90% 的分析内容消费者将借助 AI 成为内容生产者。—— Gartner 预测
```

一节里只放一条 `> ` 引用、或只有一句话时，排成整页金句，不会留一张空白要点页。

### 结束页

```markdown
## 结尾

让每个业务人员都拥有自己的分析师

GA 2027-04-15 · 2029 目标 ARR 1,633 万（自下而上测算，非业绩承诺）
```

`## 结尾`（也可写 `致谢`／`谢谢`）会排成结束页：第一段是大字，第二段是落款行。

### 三栏卡片（`###` 小标题 + 1 短句或 2–3 条要点）

```markdown
## 三条主线

### 订阅为体

按坐席年付，覆盖 60% 收入

### 用量为阀

超量按次计费，抑制滥用

### 私有化为顶

政企本地部署，客单价 3 倍
```

### 流程页（`1. 2. 3.`）

```markdown
## 最短价值闭环

1. 问数：一句话把业务问题转成查询
2. 出图：30 秒给出可解释图表
3. 推送：按周推到群与看板
```


### 章节过渡

在上一节末尾写一行 `---`，下一页会生成这一节的过渡页（大号章节号 + 标题）。

## 成稿命令

页面写好后，只运行这一条命令。不要再找别的转换器，也不要另写说明文件。

`node ../.opencode/tools/build-deck.mjs --markdown "deliverables\文件.md" --out "deliverables\文件.pptx"`

需要套用用户给的模板时再加 `--template "模板.pptx"`；不传时用仓库自带的
`.opencode/templates/master/pm-agent.potx`。命令是自包含的（不依赖 Feishu-Bridge
或任何外部转换器），路径含空格时保留双引号。不要自己打开 pptx。

命令成功时只打印一行 JSON，例如
`{"ok":true,"path":"...","bytes":8992317,"slides":9,"layouts":[...],"warnings":[]}`。
`warnings` 非空表示有条目超额或字号被压缩，回传 A0 时要说明；`ok:false` 时把
`message` 原样引用，不要给出 pptx 路径。

## 规则
- 一个 `##` 是这一节的主标题。这一节可以变成多页：正文超过 5 条要点续页，表格超过 7 行续页，图表单独成页。
- 节数在 5–8 之间时自动补一页目录；更多节时不补（目录会挤），改用 `---` 分章。
- 标题下面单独一行、不超过 28 个字、并且不以句号、叹号或问号结尾的短句，才会显示成副标题；本节第一段不超过 64 字时显示成页首导语。
- 要点用 `- `。一段写不完就继续写。
- 2–4 条「数字在前、说明在后」的要点写成 `- 1,633万 三年 ARR`，会排成指标卡；数字必须带单位（`%`、`万`、`个月`、`倍`、`人`…），说明 22 字以内。
- 三栏卡片用 `###` 小标题，每个小标题下写一句短话或 2–3 条 `- `；一页 2–3 个卡片，超过 3 个会另起一页。
- 流程用 `1. ` 有序列表，每项写成 `步骤名：一句说明`，最多 5 步。
- 多列清单、名单、需要逐项对照的数据写成 Markdown 表格，这些表会保持为表格。
- 占比写成 `chart` 的 `pie`，趋势写 `column`，对比写 `bar`。第一行是表头，后面每行一个名称和一个数字，最多 8 行。数字保持原文；需要单位时写在围栏行里，例如 `chart bar 单位:%`。
- 图表按原生形状绘制（不嵌入 Excel 对象），换机器不会变形：`pie` 是 100% 堆叠条 + 图例，`column` 是竖柱，`bar` 是横条。
- 节末的 `> ` 引用会变成这一页底部的结论条，一节只写一条。
- 不要写 `**加粗**`、`__下划线__`、行内代码或图片语法。
- 没有内容的节写一行 `- 未提供`。
- 不要写目录页和尾页，命令会按母版补上。
