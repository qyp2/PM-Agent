# S63 幻灯片大纲

## 用途
用户要 ppt 或 pptx 时，在落盘前把每一节写成下面的结构。成稿命令直接套用模板的封面、目录和尾页，只替换文字。模板里的中间页是背景样式，通常一两张，会按正文需要重复使用。一个 `##` 是一节，写不完会自动拆成后续页，不要按模板页数删内容。正文不要再写「目录」「封面」「谢谢」。明细和多列清单写成 Markdown 表格。占比写成饼图，趋势写成柱状图，对比写成条形图。材料里有几种数字，就用几种图。没有模板时才画一套新的白底页。

## 每一节

下面是一节的写法。命令会把正文、表格和图拆开：正文按内容续页，每张表和每张图单独成页，后续页标题带「（续）」。同一组数字只写一次，不要既写表又写图。

```markdown
## 页标题
副标题点明这一节

这一节用完整句子写清楚，保留名称、数字和时间，不要把一段话收成一个词。

- 要点
- 要点
```

占比用：

```chart
pie
| 项目 | 占比 |
| --- | --- |
| 名称 | 原样数字 |
```

趋势用柱状图：

```chart
column
| 项目 | 数值 |
| --- | --- |
| 名称 | 原样数字 |
```

对比用条形图：

```chart
bar
| 项目 | 数值 |
| --- | --- |
| 名称 | 原样数字 |
```

## 成稿命令

页面写好后，只运行这一条命令。不要再找别的转换器，也不要另写说明文件。

`node "D:/myproject/opencode agent structure/Feishu-Bridge/scripts/build-deck.mjs" --markdown "deliverables\文件.md" --out "deliverables\文件.pptx" --template "模板.pptx"`

路径含空格时保留双引号。没有模板时去掉 `--template`。不要自己打开 pptx。

## 规则
- 一个 `##` 是这一节的主标题。这一节可以变成多页。正文写不完会自动续页，表格和每张图各自单独成页。不要为了塞进一页而删句子。
- 标题下面单独一行、不超过 28 个字、并且不以句号、叹号或问号结尾的短句，才会显示成副标题。更长的句子，以及带句号的句子，是正文。
- 要点用 `- `。一段写不完就继续写。
- 多列清单、名单、需要逐项对照的数据写成 Markdown 表格，这些表会保持为表格。
- 占比、构成、分布写成 `chart` 里的 `pie`。趋势写成 `column`。对比写成 `bar`。第一行是表头，后面每行一个名称和一个数字，最多 12 行。数字保持原文，不要改单位。材料里有几种数字，就用几种图。不要为了凑齐三种图而改分类。
- 不要写 `**加粗**`、`__下划线__`、行内代码或图片语法。
- 没有内容的节写一行 `- 未提供`。
- 不要写目录页和尾页，命令会按模板补上。
