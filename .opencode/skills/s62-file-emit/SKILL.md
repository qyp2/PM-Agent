# S62 文件落盘技能

## 用途
把已经适配好的正文写成文件，并返回路径。

## 方法
1. 目录固定为 `deliverables/`。不存在则创建。
2. 文件名用 A0 指定的名称。未指定时用交付片段的 `title`。去掉空格和 `\ / : * ? " < > |`。
3. 始终写成 `.md`。目标是 ppt 时，按 S63 的结构写：保留主标题、副标题和完整正文，多列清单用表格，占比、趋势、对比写成 S63 规定的图。目标是 word、pdf 或 excel 时，仍写这一份 Markdown：章节用标题，多列数据用表格。桥接会生成 docx、pdf 或 xlsx，并上传到飞书聊天。有模板 pptx 时，成稿命令套用封面、目录和尾页，并用模板里的一到两种内容背景铺满正文页。不要写 `**加粗**`。不要另写说明文件。回传时写明目标格式和这份 Markdown 的路径。成稿命令成功退出后才可以写 pptx 路径。
4. 用写入工具覆盖或新建该文件。事实与 S61 的输出一致，不在落盘时改数字或删句子。ppt 的页面和图按 S63 写。
5. 若目标路径不在 `deliverables/` 下，改写到该目录后再落盘。

## 输出
- 相对路径，例如 `deliverables/需求文档.md`。
- 写入是否成功。

## 约束
- 不写 `deliverables/` 以外的路径。
- 不把空槽填上新内容。没有正文时仍写出带「未提供」的文件，避免静默失败。
