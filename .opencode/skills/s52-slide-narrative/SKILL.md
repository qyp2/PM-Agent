# S52 演示文稿制作技能

当前只保留这份规则，不接入 A61。正式出稿继续用 `s63-slide-deck` 和已选定的模板。

## 用途

把结论组织成一场有节奏的演示：观众能在 30 秒内抓住主线，在 10 分钟内理解论据，
并且每一页都"看起来像设计过的"，而不是把文档段落搬进文本框。

## 依赖库
- 知识库（产品资料、市场/竞品/运营结论）

## 方法

1. **定场景**：明确听众、时长、决策目标（知情/评审/立项/发布）。
2. **一条主线**：用一句话写出全篇主张，所有页面只服务这条主线。
3. **搭故事板**：
   - 封面：标题 + 副标题 + 场景
   - 目录：3–4 条，让听众知道还有多久
   - 结论页：先给答案
   - 2–4 个章节页：每章开头一页 `section`
   - 论据页：**一页一个观点**，观点用标题表达
   - 收尾：下一步 / 决策请求
4. **选版式**：见下方「版式选择」，同一个观点优先用有结构的版式，而不是纯 bullet。
5. **生成文件**：调用 `office_pptx`。

## 版式选择（`layout` 字段）

不写 `layout` 时，工具会按字段自动推断：有 `metrics` → 指标卡，有 `columns` → 分栏，
有 `steps` → 流程，有 `table` → 表格，有 `quote` → 金句页。

| `layout` | 何时用 | 必填内容 |
|---|---|---|
| `bullets` | 3–5 条并列论据（最常用） | `bullets` |
| `metrics` | 2–4 个关键数字 | `metrics[{value,label,note}]` |
| `columns` | 2–3 个对象/方案横向对比 | `columns[{heading,bullets}]` |
| `steps` | 3–5 步流程、路线图、里程碑 | `steps[{title,detail}]` |
| `table` | 需要逐项对齐的多维信息 | `table{headers,rows,caption}` |
| `quote` | 一句要停住听众的话（结论/客户原声） | `quote{text,source}` |
| `agenda` | 目录页 | `items[]` |
| `section` | 章节分隔（满版图） | `title`、`subtitle` |
| `closing` | 结束页 | `title`、`subtitle` |

`callout`（提示条）可加在任意内容页底部：`{label, text}`，用于"结论/风险/行动请求"。

## 版面契约（工具会自动遵守，写内容时要配合）

- 16:9，内容安全区约 `x 1.00–12.33in`、`y 1.46–6.46in`；标题带在顶部，右侧有 logo。
- 内容按可用空间自动排布：卡片/表格/分栏会撑满安全区，条目少时按行均分，不会挤在顶部。
- 字号自动适配（正文 14–26pt、指标数字 32–46pt）；超出建议条数会给出 `warnings`，
  **不要忽略 warnings**：按提示删条目或拆页。
- 母版素材（封面满版图、logo、页码域）由母版提供，不要自己再加背景图或色块。
- 中文字体使用微软雅黑，配色来自母版主题（主色 `0070C0`），不要逐页手改颜色。

## 文案规则（决定"好看"的另一半）

1. **标题是结论**：≤20 个汉字，写"首屏加载是流失主因"，不写"性能分析"。
2. **每条 ≤2 行**：一行约 26–30 个汉字；超了就拆成 `detail` 或另起一页。
3. **一页一个观点**：3–5 条并列即可，第 6 条开始拆页。
4. **数字优先**：能用 `metrics` 的不用文字；能对比的用 `columns`/`table`。
5. **每页一个视觉锚点**：要么指标卡，要么流程，要么表格，避免整页只有小字。
6. **术语一致**：同一概念全篇用同一个词，不在中英文之间反复横跳。

## 模板库

标准演示优先使用本地模板库（`template_list` / `template_get`）：

| 模板 ID | 适用 |
|---|---|
| `pptx-product-launch` | 产品发布、路演、对外介绍 |
| `pptx-quarterly-review` | 季度经营/产品复盘 |
| `pptx-project-kickoff` | 立项、启动会、里程碑对齐 |

以上模板关联 `master-pptx`（`pm-agent.potx`）。先按 `format: "pptx"` 与关键词匹配，
再读取 `fields` / `instructions` / `content`；把 `{{...}}` 全部替换为真实内容，
缺失必填字段写「【待确认】」。模板是蓝图（已用上 agenda/section/metrics/columns/
steps/table/quote/closing），可以按页增删，但保持"一页一个观点"。

`master-pptx`（`pm-agent.potx`）是 PM-Agent 的 PowerPoint 视觉母版：1 个母版、
17 个版式、封面满版图与 logo。`office_pptx` 默认复制母版包、版式、主题与媒体，
整套稿只落在两个版式上：封面/章节/结束页用 `3_自定义版式`（满版底图），
内容页统一用 `统一模板`（顶部通栏标题 ＋ 浅色底），标题与正文自动对齐母版安全区；
行距按绝对磅值写入，避免换机器/换字体后文字撑破文本框。

## 输出
- `.pptx` 文件路径、页数与页序
- 使用的模板 ID/版本与母版 ID；记录实际套用的版式（封面/内容/章节）
- 每页核心观点与数据来源
- 若返回 `warnings`，说明已如何处理（删条目/拆页/改版式）

## 约束
- 不把文档段落直接粘到幻灯片；不编造数据与案例。
- 不为了"填满页面"复述同一句话；宁可减少条目。
- 对外发布/招商材料需人工审批（R-11）。
- 只通过 `office_pptx` 生成文件；一页一个观点，避免文字墙。
