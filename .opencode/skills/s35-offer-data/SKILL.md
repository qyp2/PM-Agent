# S35 Offer 数据分析技能

## 用途
回答「我们的 Offer/营销方案盘得怎么样」类问题：组合结构、价格矩阵、促销依赖、冗余识别、修改建议。数据源是本地 CSV 快照，**一切数字以文件内容为准，不用训练数据估算**。

## 数据加载（第一步必做）

下面路径里的 `../.opencode` 是相对 **Agent 工作目录** 的上一层：工作目录是会话目录，`.opencode`（指向技能库与数据目录的链接）在工作区根。

1. 先读 `../.opencode/data/offers/README.md` 数据字典，掌握字段口径与已知缺陷。
2. 按需读 `../.opencode/data/offers/offer-plans.csv`（281 行，Offer 定价/合约/方案类型）与 `../.opencode/data/offers/product-relations.csv`（126 行，产品分类/层级）。
3. 两表无法按 ID 关联（缺陷已在 README 声明）；跨表分析用产品名近似匹配并标注。
4. **读取失败/文件缺失时**：不得对用户提及任何路径、目录或文件名。统一表述「后台数据库暂无所需资料」，再用业务语言说明缺哪类资料、补齐后能回答什么；路径细节只允许出现在给 A0 的内部回传里。

## 分析框架（按问题选路）

| 用户问题 | 分析路径 |
| --- | --- |
| 营销方案/组合怎么样 | 方案类型分布（原价 vs 促销占比）→ 价格带分布 → 团队×促销依赖交叉 |
| 某产品/某赛道如何 | 按产品名称或归属团队过滤 → 价格矩阵（月费×合约期档位）→ 促销结构 |
| 资费/定价建议 | 价格带覆盖空白档 → 同产品价格矩阵合理性（档位是否互相踩踏）→ 修改建议 |
| 冗余/瘦身 | 同产品 Offer 数排序 → 同产品同价同期重复 → 重复 Offer ID |

## 个性化指令响应

- **「生成表格」**：直接输出 Markdown 表格；行列多时给 Top N 并说明截断口径。用户要 Excel 文件时，说明走 A61 成稿链，由 A0 决定。
- **「数据可视化」**：飞书卡片不支持图表渲染，用**文字条形图**（如 `███░░ 61 条`）+ 分布表替代；用户坚持要图表文件时说明此限制并建议走成稿链生成 HTML/文档。
- **「修改建议」**：用证据链四段式（见下节），禁止无依据的泛泛建议。

## 外部证据检索（建议的依据，websearch/webfetch）

给营销建议前必须回答一句话：「**竞品用类似打法，得到了什么结果？**」检索四大运营商（HKT / 3HK / SmarTone / HKBN）的营销打法与公开效果：

1. **检索目标**：与建议方向对应的竞品打法——捆绑打包、首月减免、免费赠送、积分权益、组合包、合约期拉长——及其**公开结果**（业绩公告归因、新闻稿战报、份额变化）。
2. **推荐检索式**：「运营商名 + bundle/free months promotion + results」「运营商名 + interim/annual results + subscriber growth + 归因」「SmarTone loyalty points ARPU」「HKBN bundle strategy churn」。
3. **证据分级**：财报/业绩会归因 > 官方新闻稿战报 > 第三方分析 > 纯广告（只证明「在做」，不证明「有效」）。
4. **检索不到结果时**：只写「竞品 X 也在做此打法（来源+日期）」，**严禁编造效果数字**；建议降级为「方向性参考，效果待 FinBI 数据验证」。

## 建议输出模板（证据链四段式）

1. **结论**：一句话（我们要不要做什么）。
2. **内部证据**：CSV 实读数字（如「语音连接 81% Offer 靠促销，0 元赠送 51 条」）。
3. **外部证据**：竞品打法 + 结果 + 来源时点（如「HKT 2025 年报将宽带+娱乐捆绑归因为 ARPU 提升 x%」）；无结果数据时写「仅存在性参考」。
4. **适配建议**：结合我方站位（CMHK 大湾区/漫游/中资政企优势）给出可执行动作，标注影响面（涉及多少条 Offer）与验证方式（用哪个 FinBI 指标验收）。

## 参考基线（2026-10-22 快照实测，可直接引用）

- 方案类型：合约期原价 111 条 vs 促销类约 165 条（促销占六成）；0 元赠送 51 条。
- 价格带双峰：10-19 元 71 条、30-49 元 70 条；≥100 元仅 2 条。
- 促销依赖：云应用和智能 87%、语音连接 81%、内容互娱 50%、家庭看护 46%。
- 冗余集中区：云盘类（中国移动云盘香港版 17 + 移动云盘 14 + 移動雲盤2TB 5）；KKBOX K49 同价 44 元重复 6 条。
- 数据质量：重复 Offer ID 18 个；上线日期 75% 缺失、FinBI 通报 98% 缺失。
- 数据是快照，用户提到「最新/实时」时提醒：当前为 2026-10-22 快照，实时口径待 FinBI 同步。

## 约束

- 数字必须来自 CSV 实读或上方基线（基线注明快照日期）；统计口径写在结论里（如「按 Offer 条数，非订购量」）。
- 本数据无经营数据（订购量/收入），涉及效果的判断一律标注「待 FinBI 数据验证」。
- **外部证据必须带来源与时点**；检索不到效果数字的竞品打法只作存在性参考，不得写成「已验证有效」。
- 不做竞品专题对比（交 A12，此处检索竞品仅为建议取证）、不做市场趋势（交 A13）、不写对外文案（交 A43）。
