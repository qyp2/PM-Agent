# S61 模板适配技能

## 用途
把已经写好的正文放进模板。内容来自业务子 Agent 的 `deliverable` 块。

## 输入
- 槽位清单（`.slots.md`）或模板全文。清单来自 pptx 时，不要打开 pptx 原文件。没有模板时，按下表选用提纲。
- 一个或多个 `deliverable` 块，以及它们所属的 Agent ID。
- 用户对文件名、格式、章节的要求。

## 默认提纲
无模板时只使用与本次 Agent 对应的提纲，不合并无关章节。

|---|---|
| A11 | 背景、需求池、优先级、验收标准、待确认 |
| A12 | 竞品范围、对比矩阵、差异点、待确认 |
| A13 | 市场范围、趋势判断、机会、待确认 |
| A21 | 版本范围、里程碑、依赖、待确认 |

| A23 | 定位、卖点、发布材料、待确认 |
| A31 | 指标口径、数据、解读、待确认 |
| A32 | 反馈范围、分类、改进点、待确认 |
| A41 | 线索标准、筛选结果、待确认 |
| A42 | 跟进对象、节奏、触达材料、待确认 |

## 方法
1. 槽位只从 `.slots.md`、已给出的模板全文，或上表提纲里列。不打开 `.doc`、`.docx`、`.ppt`、`.pptx`。
2. 任务里只有一份 `deliverable` 时，先原样收下 `facts`。任务里如果还有 `.txt`，再读一次，把事实写成完整句子。不要为了缩短而删句子。多列清单写成 Markdown 表格。用户要 ppt 时，占比、趋势、对比按 S63 写成图，同一组数字只写一次。不要把事实删成一句空话，也不要另写说明文件。
3. 找不到内容的槽位写「未提供」，并记下缺失来源。不要改成向用户提问。桥接会把全部「未提供」收成一张填写卡片，用户输入并提交后才合成文件。
4. 只使用这一份摘要里的顺序，不把多份原文重新排进去。
5. 输出仍是按章节对齐的 Markdown。每个槽位一个标题。多列清单用 Markdown 表格。不要打开原文件。桥接负责合成 pptx、docx、pdf 或 xlsx。任务里有模板 pptx 路径时，pptx 会套用该文件的封面、目录和尾页，并用其中一到两种内容背景按正文页数重复。

## 输出
- 填好的 Markdown 正文。
- 已填槽位与未填槽位。

## 约束
- 不补充数据，不润色成新的判断，不把「未提供」写成推测。
- 图片保留用户给出的路径，不描述图片里没有被上游写明的内容。
